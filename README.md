# Mini Blog

My **First Laravel Project** — A Simple Blogging System

![Mini Blog Screenshot](screenshot.png)

## 📝 About the Project

**Mini Blog** is a simple blog application developed using **Laravel**. This is my very first complete web development project where I learned how to build a full-stack application.

Users can register, login, create blog posts, manage categories and tags, and view published posts.

---

## ✨ Features

- User Registration and Login
- Create, Edit, and Delete Blog Posts
- Publish / Unpublish Posts
- "My Posts" Section
- Categories Management
- Tags Management
- View All Published Posts
- Like and Comment System (Basic)
- User Profile & Logout
- Clean and Simple Interface

---

## 🛠️ Technologies Used

- **Framework**: Laravel (PHP)
- **Frontend**: Blade Templates, HTML, CSS, Bootstrap
- **Database**: MySQL
- **Authentication**: Laravel Breeze
